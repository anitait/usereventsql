E-commerce Sales Funnel Analysis | Google BigQuery & SQL
Project Overview

This project focuses on analysing e-commerce user behaviour and the purchasing journey using SQL in Google BigQuery. The objective was to understand how users move through the different stages of the sales funnel, identify potential conversion bottlenecks, evaluate the performance of different traffic sources, and derive actionable business recommendations.

The analysis was based on an event-level dataset tracking user interactions, from their initial website visit to completing a purchase.

**Tools & Technologies**

Google BigQuery – Cloud-based data warehouse and SQL environment.

SQL – Data querying, aggregation and analysis.

**Analysis Performed**

The project involved several analyses:

1. Sales Funnel Analysis

Defined five stages of the purchasing journey: page views, add to cart, checkout initiation, payment information and purchase.

Calculated the number of unique users reaching each stage.

Examined conversion rates between consecutive stages and the overall visitor-to-purchase conversion rate.

2. Conversion Analysis by Traffic Source

Compared funnel performance across different acquisition channels.

Calculated cart, purchase and overall conversion rates for each traffic source.

Identified which channels generated the strongest purchasing performance.

3. Time-to-Conversion Analysis

Reconstructed individual user journeys using event timestamps.

Calculated the average time between page views, adding products to cart and completing purchases.

Evaluated the time required for users to move through the purchasing journey.

4. Revenue Analysis

Calculated total visitors, buyers, orders and revenue.

Derived key e-commerce performance indicators, including:

Average Order Value (AOV)

Revenue per Buyer

Revenue per Visitor

**Key Findings & Business Recommendations**

The analysis highlighted several insights and potential business actions:

Email as a high-performing acquisition channel: Email generated the strongest conversion performance. A potential next step would be to introduce more prominent email capture pop-ups to grow the subscriber base and maximise this channel's potential.

Payment stage performance: The payment stage showed strong conversion performance, suggesting that the existing payment process is working effectively. Rather than introducing unnecessary changes, the priority should be to maintain the current experience.

Customer Acquisition Cost (CAC): With an average order value of approximately $115, acquisition costs should be carefully monitored. Social media advertising showed comparatively weaker conversion performance, highlighting the importance of setting strict CAC targets and ensuring that advertising spend remains profitable.

**Conclusion**

This project provided practical experience in using SQL to analyse user behaviour, measure e-commerce performance and translate quantitative findings into business recommendations.

It also demonstrated how funnel analysis can help businesses understand customer journeys, identify opportunities for optimisation and make more informed marketing and revenue decisions.

Project completed as a practical learning exercise, following a SQL and BigQuery tutorial.
